#### YOU NEED CMAKE < 3.5 !

#### WINDOWS ENVIRONMENT VARIABLES TO SET

1. **`COMMONLIB_SSE_FOLDER`**: The path to your clone of Commonlib.
2. **`VCPKG_ROOT`**: The path to your clone of [vcpkg](https://github.com/microsoft/vcpkg).
3. (optional) **`SKYRIM_FOLDER`**: path of your Skyrim Special Edition folder.
4. (optional) **`SKYRIM_MODS_FOLDER`**: path of the folder where your mods are.

#### Mod Page

[Wildfire - Nexus](https://www.nexusmods.com/games/skyrimspecialedition/mods/193507)

Wildfire is a dynamic fire simulation for Skyrim, inspired by the legendary fire mechanics of the Far Cry series, especially Far Cry 2 (2008).
With this mod, fire is no longer just a spell effect. It becomes a wild and unpredictable elemental force.
Set fire to the grass and watch it spread. Let it reach the trees. Watch the flames climb upward as branches burn away. 
A missed Fireball can ignite a field. A dragon fight can turn a forest into an inferno.
